NEXORA Panel is a self-hosted control panel for websites, databases, mail and DNS – with a dedicated Docker container for every website.

Install View source 
git clone -b nexora https://github.com/AkiraDev7004/nexora-hostingpanel.git
sudo bash nexora-hostingpanel/nexora/scripts/install.sh

Everything your server needs.

Create a website, pick a type, done. NEXORA sets up Nginx, containers, SSL and DNS automatically.

Website wizard

PHP, WordPress, Node.js, Python, static or reverse proxy – only the options each type needs.

One container per website

Own network, non-root, no capabilities, read-only root FS, CPU and RAM limits.

Let's Encrypt

Certificates at creation time, automatic renewal, HTTP→HTTPS.

Your own DNS servers

Manage zones and records. Authoritative servers stay strictly non-recursive.

DNS blocking

Block domains, subdomains and wildcards. NXDOMAIN, 0.0.0.0 or sinkhole. Blocklists via URL.

Mail

Postfix, Dovecot and Roundcube – or Mailcow as a central instance when Docker is available.

IPv4 & IPv6

Multiple IPs, assigned per website. Only IPs that are actually configured on the server.

API

API keys with permissions and expiry. Secrets are stored hashed only.

OLED Dark Mode

True black, clear contrast, no effects. Optional light mode.

Two operating modes.

The installer tests Docker with a real test container and picks the right mode.

Recommended

Full Docker Mode

  • Dedicated container per website
  • Isolated networks
  • Resource limits & monitoring
  • Mailcow available
For restricted systems

Classic Hosting Mode

  • Linux user & PHP-FPM pool per website
  • Ideal for Proxmox LXC without Docker
  • Postfix, Dovecot, Roundcube
  • Less isolation than Docker – clearly labeled

Installed in minutes.

Debian 11–13 or Ubuntu 22.04 / 24.04. For the best Docker compatibility we recommend a dedicated VM.

OS, virtualization, hardware, network.

Docker test
