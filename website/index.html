NEXORA Panel ist ein selbst gehostetes Control Panel für Websites, Datenbanken, Mail und DNS – mit einem eigenen Docker-Container pro Website.

Installieren Quellcode ansehen 
git clone -b nexora https://github.com/AkiraDev7004/nexora-hostingpanel.git
sudo bash nexora-hostingpanel/nexora/scripts/install.sh

Alles, was ein Server braucht.

Website erstellen, Typ wählen, fertig. Nginx-Konfiguration, Container, SSL und DNS richtet NEXORA automatisch ein.

Website-Wizard

PHP, WordPress, Node.js, Python, Static oder Reverse Proxy – nur die Optionen, die der Typ braucht.

Ein Container pro Website

Eigenes Netzwerk, non-root, keine Capabilities, read-only Root-FS, CPU- und RAM-Limits.

Let's Encrypt

Zertifikate direkt bei der Erstellung, automatische Verlängerung, HTTP→HTTPS.

Eigene DNS-Server

Zonen und Records verwalten. Authoritative Server bleiben strikt nicht-rekursiv.

DNS-Blocking

Domains, Subdomains und Wildcards blockieren. NXDOMAIN, 0.0.0.0 oder Sinkhole. Blocklisten per URL.

Mail

Postfix, Dovecot und Roundcube – oder Mailcow als zentrale Instanz, wenn Docker verfügbar ist.

IPv4 & IPv6

Mehrere IPs, Zuweisung pro Website. Nur IPs, die wirklich auf dem Server konfiguriert sind.

API

API-Keys mit Berechtigungen und Ablaufdatum. Secrets werden nur gehasht gespeichert.

OLED Dark Mode

Echtes Schwarz, klare Kontraste, keine Effekte. Light Mode optional.

Zwei Betriebsmodi.

Der Installer testet Docker mit einem echten Testcontainer und wählt den passenden Modus.

Empfohlen

Full Docker Mode

  • Eigener Container pro Website
  • Isolierte Netzwerke
  • Ressourcenlimits & Monitoring
  • Mailcow verfügbar
Für eingeschränkte Systeme

Classic Hosting Mode

  • Linux-User & PHP-FPM-Pool pro Website
  • Ideal für Proxmox LXC ohne Docker
  • Postfix, Dovecot, Roundcube
  • Weniger Isolation als Docker – klar gekennzeichnet

In Minuten installiert.

Debian 11–13 oder Ubuntu 22.04 / 24.04. Für beste Docker-Kompatibilität empfehlen wir eine dedizierte VM.

Systemprüfung

OS, Virtualisierung, Hardware, Netzwerk.

Docker-Test

Echter Container-Start statt Annahmen.

Komponenten

Complete, Minimal oder Custom.

Fertig

Panel-URL und Admin-Zugang.
